# VFD Spectrum

90〜2000年代のカーオーディオ風の、蛍光表示管（VFD）スペクトラムアナライザーです。
ブラウザ（HTML5 Canvas + Web Audio）で動き、Mac アプリ版もあります。外部のサーバーとは通信しません。

## フォルダ
| 場所 | 内容 |
|---|---|
| `index.html` `style.css` `js/` | アプリ本体（ビルド不要） |
| `macos/` | Mac アプリ（`macos/build.sh` で `VFD Spectrum.app` を作ります） |
| `server.py` `start.command` | Mac 用の補助サーバー（Music アプリの曲名を表示する用） |
| `web-assets/` `tools/` | ブラウザ／iPad 配布用の素材と、`dist/` を作るスクリプト |
| `dist/` | **ブラウザ／iPad 用の配布物**（これをそのまま公開します） |

## iPad などで使う（ブラウザ版）
1. `dist/` を静的サイトとして公開します（下の「公開のしかた」）。
2. iPad の Safari でそのアドレスを開き、共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから起動すると全画面で動きます。最初に一度だけ、マイクの使用を許可してください。
4. 画面下の「表示拡大」でディスプレイだけを大きく表示できます。一度読み込めば、電波のない場所でも動きます。

音は、iPad ではマイクで拾うか、音楽ファイルをこのアプリで再生して解析します（再生中の音そのものを取り込めるのは Mac アプリだけです）。

## 更新のしかた
ソースを直したら、`python3 tools/build_web.py` を実行して `dist/` を作り直し、コミットして公開します
（サービスワーカーの版が自動で変わり、iPad 側は次の起動で新しくなります）。

## 公開のしかた（非公開リポジトリのまま使う場合）
GitHub Pages は、無料プランでは公開リポジトリでしか使えません。非公開のまま公開するには、次のどちらかです。
- **Cloudflare Pages（無料）**: GitHub のリポジトリを連携し、ビルドコマンドは空、出力ディレクトリは `dist`。
- **GitHub Pro（有料）** で GitHub Pages を使う（出力元はブランチ内の `dist`、または GitHub Actions）。

どちらの場合も、サイトのアドレスを知っている人は誰でも開けます。`dist/` には検索エンジンに載せない設定
（`noindex`）と、外部へ通信できない設定（Content-Security-Policy）を入れてあります。
